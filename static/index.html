Academic Reference & Curriculum Mapping

Classical ML vs Deep Learning Foundations

Core theoretical concepts, mathematical formulas, and algorithmic design choices for 5th Semester B.Tech Machine Learning coursework.

P(c|d)

1. Multinomial Naive Bayes

Applies Bayes' Theorem with the naive independence assumption between features. Features represent term frequencies or TF-IDF weights:

$$P(c \mid d) \propto P(c) \prod_{i=1}^{n} P(w_i \mid c)$$ $$P(w_i \mid c) = \frac{N_{ci} + \alpha}{N_c + \alpha |V|}$$

Laplace smoothing ($\alpha=1.0$) prevents the zero-probability problem for words unobserved in a class.

k-NN

2. K-Nearest Neighbors ($k=5$, Cosine)

Non-parametric lazy learner calculating proximity in 2500-dimensional sparse TF-IDF space. Uses Cosine Distance rather than Euclidean to disregard document length variations:

$$\text{Cosine Similarity}(\vec{u}, \vec{v}) = \frac{\vec{u} \cdot \vec{v}}{\|\vec{u}\|_2 \|\vec{v}\|_2}$$ $$d_{\text{cosine}}(\vec{u}, \vec{v}) = 1 - \text{Cosine Similarity}$$

Majority voting among the $k=5$ closest document vectors determines the class label.

σ(z)

3. Logistic Regression (Multinomial Softmax)

Linear model mapping feature weighted sums through the softmax link function to yield calibrated posterior class probabilities:

$$P(y = k \mid \vec{x}) = \frac{e^{\vec{w}_k^T \vec{x} + b_k}}{\sum_{j=1}^{K} e^{\vec{w}_j^T \vec{x} + b_j}}$$

Trained with L2 ridge regularization ($C=1.0$) to prevent overfitting on high-dimensional sparse text.

SVM

4. Linear Support Vector Machine (Linear SVM)

Constructs optimal separating hyperplanes maximizing the geometric margin between classes with soft-margin slack variables $\xi_i$:

$$\min_{\vec{w}, b, \xi} \frac{1}{2}\|\vec{w}\|^2 + C \sum_{i=1}^{N} \xi_i$$ $$\text{subject to } y_i(\vec{w}^T \vec{x}_i + b) \ge 1 - \xi_i, \quad \xi_i \ge 0$$

Linear SVM excels in text classification due to high sparsity and linear separability in high-dimensional TF-IDF space.
